# Rock Paper Scissors

This project is a full-stack web application that allows users to play the classic Rock Paper Scissors game against a computer. The application tracks player statistics, including wins, losses, draws, and win streaks, and provides a leaderboard to display top performers.

## Features
- Interactive UI for playing Rock Paper Scissors.
- Persistent player statistics stored in MongoDB.
- Global leaderboard showing the top 5 players.
- Responsive design using Tailwind CSS.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS.
- **Backend**: Node.js, Express.
- **Database**: MongoDB (via Mongoose).
